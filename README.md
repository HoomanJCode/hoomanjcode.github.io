## ✨ What This Is

A **static generative portfolio** built with love, code, and cosmic dust.

Every visual element is **procedurally generated** — no images, no assets, just pure code creating art in real-time. The Three.js planet, the scroll animations, the particle systems — all born from algorithms.

## 🚀 Quick Start

### Clone & Run

```bash
git clone https://github.com/HoomanJCode/hoomanjcode.github.io.git
cd hoomanjcode.github.io
python3 -m http.server 4173
```

Then open **http://localhost:4173** 🎉

> 📡 *The 3D scene requires an internet connection (loads Three.js from CDN)*

## 🎨 Design Philosophy

```
    ╭──────────────────────────────────────────╮
    │                                          │
    │   "Technology is my raw material."       │
    │                                          │
    │   From a single line of code to a        │
    │   whole universe of rules, I look for    │
    │   the point where engineering becomes    │
    │   expression.                            │
    │                                          │
    ╰──────────────────────────────────────────╯
```

- **Procedural > Static** — Every visual is generated, not designed
- **Performance First** — IntersectionObserver, requestAnimationFrame, reduced motion support
- **Accessible** — ARIA labels, keyboard navigation, screen reader friendly
- **Responsive** — Works on mobile, tablet, and desktop
